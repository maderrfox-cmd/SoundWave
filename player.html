        Spotify

        Connecte YouTube

        SoundWave a besoin d'une clé YouTube gratuite pour chercher la musique. Ça prend 5 minutes, une seule fois :

        1. Ouvre Google Cloud et crée un projet (n'importe quel nom).
        2. Active YouTube Data API v3 (bouton « Activer »).
        3. Va dans Identifiants → « Créer des identifiants » → « Clé API », puis copie-la ici.

        Spotify

        SoundWave lit tes playlists Spotify et les joue via YouTube. Il faut une clé Spotify (le compte qui la crée doit avoir Premium). À faire une seule fois :

        1. Ouvre le tableau de bord Spotify, connecte-toi et clique sur « Create app ».
        2. Nom et description au choix. Dans « Redirect URIs », colle exactement , puis « Add ».
        3. Coche « Web API », accepte les conditions et clique sur « Save ».
        4. Dans l'appli, va dans « Settings », copie le « Client ID » et colle-le ici.
